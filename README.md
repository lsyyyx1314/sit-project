大学生创新创业训练计划（创新训练项目）原型代码。

**能验证、验证快、开销低、可定位**。

- 计划书：[`docs/项目实施与开发计划书.md`](docs/项目实施与开发计划书.md)

## 快速开始

```bash
# 1. 环境（Ubuntu 24.04，幂等）
bash scripts/provision.sh

# 2. 测试
. .venv/bin/activate
python -m pytest -q

# 3. R1 反例取证
python -m sim.counterexample_r1 --json

# 4. BPMV 基准
python -m sim.bench_bpmv --json
```

## 当前实现要点

1. **定长验证头**：16 字节（nonce 64 bit + tag 64 bit），与跳数无关。
2. **逐跳更新**：`tag_i = D(K_i, nonce ‖ tag_{i-1})`，前序状态参与摘要，
   因此对跳顺序敏感（R2）。
3. **随机数处理**：nonce 明文携带、不进入需要「消去」的指数位置（R1）。
4. **多路径判定**：`PathSet` 前缀树，一次遍历完成候选集判定。
