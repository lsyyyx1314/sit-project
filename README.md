# SIT — 面向软件定义网络的高效多路径验证研究

大学生创新创业训练计划（创新训练项目）原型。实现语言 **C++17，零外部依赖**。

把「验证一条固定路径」扩展为「验证一个合法路径集合」：数据包逐跳维护 16 字节定长
验证头，出口上报控制器，控制器据此判定路径合法性，并在失败时定位到分歧交换机。

- 计划书：`docs/项目实施与开发计划书.md`
- 算法与验证报告：`docs/算法设计与验证报告.md`
- 项目总说明：`PROJECT.md`

## 快速开始

```bash
make            # 编译（g++ >= 11）
make test       # 黄金向量交叉校验 + 功能/对抗断言
make bench      # 攻击矩阵与性能基准
sudo make e2e   # 端到端：4 台软件交换机，双向双路径
```

## 核心设计

随机性放在**线性项**而非指数上，因此不需要「消去随机数」：

```
h    = H(nonce)                  公开哈希
c_i  = (a_i + b_i·h) mod p       单跳贡献
V    = Σ c_i·ρ^(i-1) mod p       逐跳累积，ρ 位置加权绑定顺序
E(P) = A_P + B_P·h               控制器期望值（与 nonce 无关，可预计算）
```

- 头部恒定 16 字节：nonce 56 + V 64 + tag 8
- 判定 O(1)：按 tag 直接比对；tag 不可信时退化为 O(k) 扫描
- 流级压缩：按 tag 分组累加，N 包 → ≤k 条
