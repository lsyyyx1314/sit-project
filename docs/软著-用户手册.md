# MPV-2 多路径路径验证原型系统 V1.0 — 用户手册（软件著作权申请底稿）

软件全称：面向软件定义网络的多路径路径验证原型系统（MPV-2）
版本号：V1.0　开发完成日期：2026-10-31　发表状态：未发表
开发完成环境：Ubuntu 24.04（内核 6.x），g++ ≥ 11，GNU Make，iproute2

---

## 1. 软件用途

本软件在软件定义网络（SDN）多路径转发环境下，为数据包生成、逐跳维护定长
（16 字节）验证头，并在出口处向控制器上报验证信息；控制器据此判定数据包是否
沿合法路径集合中的某一条转发，失败时逐跳取证定位嫌疑交换机（多故障同时报出
全部嫌疑），支持流级压缩判定（CFMV）、重放识别与链路故障切换下的验证协同。

适用场景：SDN 可信转发研究与教学演示、路径验证算法评估、网络异常定位实验。

## 2. 运行环境

| 项 | 要求 |
|---|---|
| 操作系统 | Ubuntu 22.04 / 24.04（Linux，需 root 权限运行端到端与演示） |
| 编译器 | g++ ≥ 11（C++17） |
| 构建 | GNU Make |
| 系统工具 | iproute2（`ip` 命令，netns/veth 拓扑） |
| 硬件 | 2 vCPU / 2GB 内存即可；建议 4 vCPU |

不依赖任何第三方库、脚本解释器或容器。

## 3. 安装与编译

```bash
make deps       # 可选：安装 g++ / make / iproute2（幂等）
make            # 编译全部 7 个可执行文件到 cpp/build/
make test       # 自检：黄金向量交叉校验 + 700 项功能/对抗断言
```

## 4. 功能与操作

### 4.1 离线基准（bench，无需 root）

```bash
./cpp/build/bench
```

输出：十类攻击检出矩阵、多候选矩阵（k=2/8/16）、控制器判定时延 vs k、
流级判定时延 vs N、解析基线对比。结果写入 `results/bench_report.md`。

### 4.2 端到端验证（e2e，需 root）

```bash
sudo ./cpp/build/e2e        # 或 sudo make e2e
```

自动完成：创建 h1/h2 网络命名空间与 6 条 veth → 拉起 4 台软件交换机 →
依次执行 7 轮场景（正常转发 / 标签错配 / 恶意改头 / 恶意重放 / 流级压缩 /
链路故障切换 / 多重故障）→ 汇总检出、定位与误报统计。
结果写入 `results/e2e_report.md`。

### 4.3 结题实验套件（exp，需 root）

```bash
sudo ./cpp/build/exp [--trials 10000] [--rounds 5] [--pings 20]
```

一键运行 11 组实验：攻击矩阵、多候选、时延 vs k、流级与吞吐、通信开销、
头长对比、端到端统计、存储开销、定位成功率、算法级基线对比、规模扩展；
自动生成 `results/exp_report.md` 与 `results/charts/*.svg`（3 张新图：
chart_storage / chart_baseline / chart_hops）。

### 4.4 演示控制台（dashboard，需 root）

```bash
sudo ./cpp/build/dashboard --port 8080
# 浏览器打开 http://<主机地址>:8080
```

功能：实时拓扑动画；七种场景一键注入（正常 / 标签错配 / 黑洞偏离 / 恶意改头 /
恶意重放 / 链路故障切换 / 多重故障）；失败包自动定位嫌疑交换机并在拓扑标红；
BPMV / CPMV / CFMV 判定开销实时对比；流级压缩窗口实时判定。

### 4.5 单交换机（vswitch）与离线验证器（verify_reports）

```bash
./cpp/build/vswitch --sid 2 --ports 1:s2p1,2:s2p2 --trace --flow-window 16
                  [--evil bitflip|dup]      # 恶意模式：改头 / 重放
./cpp/build/verify_reports <上报文件>       # 读上报文件输出判定与定位
```

上报行格式（控制器与 verify_reports 共用）：

```
<sid> <tag> <nonce> <acc> <dst_mac>                      逐包上报
FLOW <dst_mac> <tag> <N> <sum_h> <sum_v>                 流级聚合（CFMV）
TRACE <dst_mac> <sid> <in> <out> <tag> <nonce> <pos> <V> 逐跳取证
```

## 5. 注意事项

1. e2e 与 dashboard 共用 `/tmp/mpv_run` 工作目录与 h1/h2 命名空间名，
   **不可同时运行**；异常退出后重跑会自动清理。
2. 端到端与演示需要 root（创建 netns、AF_PACKET 收发）。
3. 时延类测量要求稳定的时钟源：虚拟机若长期挂起后恢复，可能出现 hypervisor
   对 RDTSC 的陷入（表现为所有 µs 级测量放大数十倍），需整机断电重启后重测。
4. 局限：64 位素数域为演示级强度；用户态交换机吞吐 ~3000 pps（功能验证口径，
   与控制器判定吞吐解耦）。

## 6. 常见问题

| 现象 | 处理 |
|---|---|
| `make test` 失败 | 确认 g++ ≥ 11：`g++ --version`；清理后 `make clean && make` |
| e2e 报 "Operation not permitted" | 需要 sudo；确认 `/dev/net/tun` 与 netns 可用 |
| 浏览器打不开 8080 | 防火墙放行；或 `--port` 换端口；重启演示服务 |
| 时延数字异常大 | 见 5.3，整机断电重启虚拟机后重跑 |
